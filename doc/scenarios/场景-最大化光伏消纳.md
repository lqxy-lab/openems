# 场景-最大化光伏消纳

## 1. 场景概述

最大化光伏自消纳是指通过智能控制，使光伏系统产生的电能尽可能多地被本地负载消耗或存储，减少向电网的馈送，从而提高能源利用效率并降低用户电费。

OpenEMS 中主要通过 `Controller.Ess.GridOptimizedCharge` 控制器实现这一功能，该控制器结合了**预测性延迟充电**和**上网功率限制**两种策略。

## 2. 业务逻辑

### 2.1 核心目标
- **减少电网依赖**：尽可能使用本地产生的光伏电能，减少从电网购电
- **提高能源利用效率**：避免光伏电能浪费，最大化本地消纳
- **降低用户电费**：减少高峰时段用电，利用峰谷电价差
- **减轻电网压力**：减少光伏大发时对电网的冲击

### 2.2 基本原理
当光伏系统产生电能时：
1. **优先供给本地负载**：直接满足当前用电需求
2. **多余电能存储到电池**：当负载需求小于光伏出力时，将多余电能存储起来
3. **限制向电网馈送**：当电池充满或无法存储时，限制光伏出力或向电网馈送功率

### 2.3 典型场景
- **白天光伏出力充足**：优先满足负载，多余电能充电到电池
- **傍晚光伏出力下降**：电池开始放电，补充负载需求
- **夜间无光伏出力**：电池继续放电，不足时从电网购电

## 3. 算法实现逻辑

OpenEMS 使用 `GridOptimizedCharge` 控制器实现最大化光伏自消纳，核心算法包括两种策略：

### 3.1 预测性延迟充电

**核心思想**：基于光伏出力预测，延迟电池充电时间，让负载优先消耗光伏电能。

**实现原理**：
1. **功率预测**：使用 `PredictorManager` 预测未来光伏出力和负载需求
2. **充电时间计算**：根据预测结果，计算最佳充电开始时间
   - 目标：在日落前充满电池
   - 方法：基于当前SOC、电池容量、预测功率计算所需充电时间
3. **动态调整充电功率**：根据实时功率情况，调整电池充电功率

**公式简化**：
```
所需充电时间 = (目标容量 - 当前容量) / 充电功率
最佳充电开始时间 = 日落时间 - 所需充电时间
```

### 3.2 上网功率限制

**核心思想**：当光伏出力超过本地负载需求，导致向电网馈送功率超过设定阈值时，通过控制电池充电，消耗多余光伏电能。

**实现原理**：
1. **实时监测上网功率**：通过电表数据获取当前向电网馈送的功率
2. **计算目标充电功率**：
   - 目标：使上网功率不超过设定阈值
   - 方法：目标充电功率 = 当前上网功率 - 设定阈值
3. **执行充电控制**：调整电池充电功率，消耗多余光伏电能

**公式简化**：
```
目标充电功率 = 当前上网功率 - 设定的最大上网功率
```

### 3.3 两种策略的协同
- **优先级**：当两种策略产生冲突时，上网功率限制策略优先
- **切换逻辑**：根据实时功率情况动态切换
  - 当上网功率未超过限制时，使用预测性延迟充电
  - 当上网功率超过限制时，强制电池充电

#### 4.2.2 周期执行流程 (1秒/次)

```java
// 1. 前置检查
run()
├── updateMaximumSellToGridPower()  // 更新最大上网功率
├── 检查 ESS 是否可管理
├── 检查生产功率数据是否有效
└── 午夜重置通道

// 2. 启动条件判断
└── 检查是否需要启动控制逻辑
    ├── 计算过去100秒的生产和消费平均值
    └── 如果生产 > 消费 + 缓冲，记录启动时间

// 3. 控制策略执行
├── 根据模式（OFF/AUTOMATIC/MANUAL）执行不同逻辑
│   ├── OFF：仅执行上网功率限制
│   ├── AUTOMATIC：执行预测性延迟充电 + 上网功率限制
│   └── MANUAL：使用手动配置的目标时间
└── predictChargeStart()  // 预测充电开始时间

// 4. 应用功率限制
└── applyCalculatedPowerLimits()
    ├── 计算 AC 充电限制
    ├── 如果上网功率限制更严格，优先使用
    ├── 应用延迟充电最大功率限制
    └── 应用上网功率限制最小充电功率
```

#### 4.2.3 关键代码实现

**预测充电开始时间**：
```java
private void predictChargeStart() {
    var targetTime = this.getTargetMinute().orElse(DEFAULT_TARGET_TIME);
    var capacity = this.ess.getCapacity().getOrError();
    var soc = this.ess.getSoc().getOrError();
    
    // 计算最佳充电开始时间
    Long epochChargeStartTime = DelayCharge.getPredictedChargeStart(
        targetTime, capacity, soc, this.componentManager.getClock());
    
    // 更新预测充电开始时间通道
    this._setPredictedChargeStartEpochSeconds(epochChargeStartTime);
}
```

**应用功率限制**：
```java
private void applyCalculatedPowerLimits(Integer sellToGridLimit, Integer delayChargeLimit) {
    // 如果上网功率限制 < 延迟充电限制，优先使用上网功率限制
    if (sellToGridLimit != null && delayChargeLimit != null) {
        if (sellToGridLimit <= delayChargeLimit) {
            this.ess.setActivePowerEquals(sellToGridLimit);
            return;
        }
    }
    
    // 应用延迟充电限制
    if (delayChargeLimit != null) {
        // 根据DC生产功率计算AC限制
        delayChargeLimit = this.calculateDelayChargeAcLimit(delayChargeLimit);
        this.delayCharge.applyCalculatedLimit(delayChargeLimit);
    }
    
    // 应用上网功率限制
    if (sellToGridLimit != null) {
        this.sellToGridLimit.applyCalculatedMinimumChargePower(sellToGridLimit);
    }
}
```

### 4.3 数据流向

```
1. 数据采集
   - 光伏逆变器 → 功率数据 → Sum 组件
   - 电表 → 负载/电网功率 → Sum 组件
   - 电池 → SOC/功率 → ESS 组件

2. 数据处理
   - Sum 组件汇总数据 → GridOptimizedCharge 控制器
   - PredictorManager 提供功率预测 → GridOptimizedCharge 控制器

3. 控制决策
   - GridOptimizedCharge 控制器计算目标功率 → ESS 组件

4. 执行控制
   - ESS 组件将控制命令下发到电池 → 电池执行充放电

5. 反馈调整
   - 电池执行结果 → 数据采集 → 下一周期重新计算
```

## 5. 核心配置与调整

### 5.1 主要配置参数
- **mode**：控制模式（OFF/AUTOMATIC/MANUAL）
- **maximumSellToGridPower**：最大允许上网功率
- **manualTargetTime**：手动模式下的目标充电时间
- **delayChargeEnabled**：是否启用延迟充电
- **sellToGridLimitEnabled**：是否启用上网功率限制

### 5.2 调整策略
- **夏季**：延长充电时间，充分利用光伏出力
- **冬季**：提前充电，确保夜间用电需求
- **高峰电价时段**：增加电池放电功率，减少电网购电
- **低谷电价时段**：允许从电网购电充电（根据配置）

## 6. 总结

最大化光伏自消纳是通过智能控制实现光伏电能的高效利用，OpenEMS 使用 `GridOptimizedCharge` 控制器结合预测性延迟充电和上网功率限制两种策略，实现了从数据采集、预测、决策到执行的完整闭环控制。

这种设计既考虑了实时功率平衡，又结合了未来功率预测，能够在不同场景下灵活调整控制策略，最大化本地光伏消纳率，同时兼顾用户需求和电网安全。

通过合理配置和调整控制器参数，可以根据不同地区的光照条件、电价政策和用户需求，优化光伏自消纳效果，实现经济效益和环境效益的双赢。
