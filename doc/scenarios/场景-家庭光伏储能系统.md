# 场景-家庭光伏储能系统

## 1. 业务场景逻辑

### 1.1 场景概述

家庭光伏储能系统是指将太阳能光伏发电系统与储能电池系统相结合，实现本地能源生产、存储和消费的一体化管理。该系统可以提高光伏能源的自消纳率，降低用户电费，并在电网故障时提供备用电源。

### 1.2 设备组成

- **光伏逆变器**：将光伏组件产生的直流电转换为交流电，支持Fronius、GoodWe、SMA等主流品牌
- **储能系统**：包括电池组和电池管理系统(BMS)，用于存储多余的光伏电能
- **双向电表**：测量家庭与电网之间的能量交换
- **家庭负载**：包括照明、家电等各类用电设备

### 1.3 控制目标

- **最大化光伏自消纳**：优先使用本地光伏电能，减少向电网馈送
- **峰谷电价优化**：在电网低谷时段充电，高峰时段放电，利用电价差降低电费
- **保障家庭供电可靠性**：在电网故障时，储能系统可作为备用电源

### 1.4 运行模式

#### 1.4.1 并网模式

- **光伏充足时**：光伏电能优先供给负载，多余电能充电到电池，电池充满后限制光伏出力或向电网馈送
- **光伏不足时**：负载由电池和电网共同供电，优先使用电池电能
- **无光伏时**：负载由电池供电，电池SOC达到下限后切换到电网供电

#### 1.4.2 离网模式

- 电网故障时，系统自动切换到离网模式
- 负载完全由光伏和电池供电
- 当光伏和电池无法满足负载需求时，系统按优先级切除部分负载

### 2.3 算法逻辑

#### 2.3.1 最大化光伏自消纳算法

**核心算法**：结合预测性延迟充电和上网功率限制

1. **预测性延迟充电**
   - 基于光伏出力预测，延迟电池充电时间
   - 目标：在日落前充满电池
   - 计算公式：
     ```
     所需充电时间 = (目标容量 - 当前容量) / 充电功率
     最佳充电开始时间 = 日落时间 - 所需充电时间
     ```

2. **上网功率限制**
   - 实时监测向电网馈送的功率
   - 当馈送功率超过设定阈值时，增加电池充电功率
   - 计算公式：
     ```
     目标充电功率 = 当前上网功率 - 设定的最大上网功率
     ```

#### 2.3.2 峰谷电价优化算法

**核心思想**：根据分时电价，优化电池充放电时间

1. **电价预测**：通过`TimeOfUseTariff`模块获取未来电价信息
2. **优化目标**：最小化用电成本，最大化售电收益
3. **优化策略**：
   - 低谷时段（电价低）：优先充电，从电网购电充电
   - 高峰时段（电价高）：优先放电，减少从电网购电
   - 平峰时段：根据预测的光伏出力和负载需求调整充放电策略

public class ControllerEssGridOptimizedChargeImpl implements ControllerEssGridOptimizedCharge {

            if ((production <= 100) || (production <= consumption + DEFAULT_POWER_BUFFER)) {
                return;
            }
            this._setStartEpochSeconds(LocalTime.now(clock), clock);
        }
        
        // 3. 执行控制策略
        Integer sellToGridLimitMinChargePower = null;
        Integer delayChargeMaxChargePower = null;
        
        switch (this.config.mode()) {
            case AUTOMATIC:
                // 自动模式：同时执行两种策略
                sellToGridLimitMinChargePower = this.sellToGridLimit.getSellToGridLimit();
                delayChargeMaxChargePower = this.delayCharge.getPredictiveDelayChargeMaxCharge();
                break;
            // 其他模式处理...
        }
        
        // 4. 应用功率限制
        this.applyCalculatedPowerLimits(sellToGridLimitMinChargePower, delayChargeMaxChargePower);
    }
    
    // 应用功率限制的核心逻辑
    private void applyCalculatedPowerLimits(Integer sellToGridLimit, Integer delayChargeLimit) {
        // 如果上网功率限制更严格，优先使用
        if (sellToGridLimit != null && delayChargeLimit != null) {
            if (sellToGridLimit <= delayChargeLimit) {
                this.ess.setActivePowerEquals(sellToGridLimit);
                return;
            }
        }
        
        // 应用延迟充电限制
        if (delayChargeLimit != null) {
            delayChargeLimit = this.calculateDelayChargeAcLimit(delayChargeLimit);
            this.delayCharge.applyCalculatedLimit(delayChargeLimit);
        }
        
        // 应用上网功率限制
        if (sellToGridLimit != null) {
            this.sellToGridLimit.applyCalculatedMinimumChargePower(sellToGridLimit);
        }
    }
}

### 3.3 峰谷电价优化控制器

`TimeOfUseTariffControllerImpl`实现了基于分时电价的充放电控制：

```java
public class TimeOfUseTariffControllerImpl extends AbstractOpenemsComponent implements TimeOfUseTariffController {
    
    @Reference
    private TimeOfUseTariff timeOfUseTariff; // 分时电价数据
    
    @Reference
    private ManagedSymmetricEss ess; // 储能系统
    
    @Reference
    private Sum sum; // 系统汇总数据
    
    @Override
    public void run() throws OpenemsNamedException {
        // 1. 获取当前和预测的电价信息
        var currentPrice = this.timeOfUseTariff.getCurrentPrice();
        var pricePrediction = this.timeOfUseTariff.getPricePrediction();
        
        // 2. 获取系统状态
        var soc = this.ess.getSoc().getOrError();
        var gridActivePower = this.sum.getGridActivePower().getOrError();
        
        // 3. 执行状态机逻辑
        var context = new Context(
            this.config,
            this.ess,
            this.sum,
            this.timeOfUseTariff,
            this.energyScheduleHandler
        );
        
        // 4. 根据状态机结果设置目标功率
        var result = this.stateMachine.run(context);
        this.applyResult(result);
    }
    
    // 应用控制结果
    private void applyResult(Result result) throws OpenemsNamedException {
        switch (result.applyMode) {
            case APPLY_PID:
                // 使用PID控制器平滑调整功率
                this.ess.setActivePowerEqualsWithPid(result.targetPower);
                break;
            case APPLY_DIRECT:
                // 直接设置目标功率
                this.ess.setActivePowerEquals(result.targetPower);
                break;
            case NO_APPLY:
                // 不执行任何操作
                break;
        }
    }
}
```

### 3.4 数据汇总组件

public class SumImpl extends AbstractOpenemsComponent implements Sum {
    
    @Override
    public void updateChannelsBeforeProcessImage() {
        // 汇总光伏生产功率
        int productionPower = this.calculateProductionPower();
        this._setProductionActivePower(productionPower);
        
        // 汇总负载功率
        int consumptionPower = this.calculateConsumptionPower();
        this._setConsumptionActivePower(consumptionPower);
        
        // 计算电网功率
        int gridPower = consumptionPower - productionPower - this.calculateEssPower();
        this._setGridActivePower(gridPower);
    }
}

## 4. 配置与调整

### 4.1 主要配置参数

| 参数 | 描述 | 默认值 |
|------|------|--------|
| `maximumSellToGridPower` | 最大允许向电网馈送的功率 | -1 (无限制) |
| `delayChargeEnabled` | 是否启用预测性延迟充电 | true |
| `sellToGridLimitEnabled` | 是否启用上网功率限制 | true |
| `mode` | 控制模式 (OFF/AUTOMATIC/MANUAL) | AUTOMATIC |
| `socMin` | 电池最小SOC限制 | 20% |
| `socMax` | 电池最大SOC限制 | 90% |

### 4.2 调整策略

- **夏季**：延长充电时间，充分利用光伏出力
- **冬季**：提前充电，确保夜间用电需求
- **高峰电价时段**：增加电池放电功率，减少电网购电
- **低谷电价时段**：允许从电网购电充电，降低用电成本

3. **实时的数据监控**：提供完整的系统状态监测和历史数据分析
